# SemAlign-TS

Official anonymous implementation for **SemAlign-TS: Observable Semantic Alignment for Controllable Text-to-Time-Series Generation**.

SemAlign-TS is a controllable text-to-time-series generation framework that separates **textual conditioning** from **observable semantic alignment**. A compact text-conditioned diffusion model is first pretrained, and then fine-tuned with **Observable Semantic Relative Alignment (OSRA)** to improve controllability over measurable temporal attributes such as trend direction, volatility level, and peak timing.

## Overview

The pipeline contains three stages:

1. **Diffusion pretraining**: train a text-conditioned temporal diffusion denoiser.
2. **OSRA fine-tuning**: align generated candidates using observable semantic rewards.
3. **Evaluation**: report distance-oriented fidelity metrics and semantic control metrics.

The implementation supports six time-series benchmarks used in the paper:

* ETTh1
* ETTm1
* Electricity
* Exchange Rate
* Traffic
* Weather

## Quick Start

Run the full pipeline on one dataset, for example ETTh1.

### Step 1: Diffusion Pretraining

```bash
python diff_train.py --dataset etth1
```

The best diffusion checkpoint will be saved to:

```text
checkpoints/diff_train/etth1/best_model.pt
```

### Step 2: OSRA Fine-tuning

```bash
python osra_train.py --dataset etth1
```

This step loads the pretrained diffusion checkpoint and saves the OSRA model to:

```text
checkpoints/osra/main/etth1/best_model.pt
```

### Step 3: Evaluation

Evaluate the diffusion-pretrained baseline:

```bash
python evaluate.py --dataset etth1 --mode diff_train
```

Evaluate the OSRA-aligned model:

```bash
python evaluate.py --dataset etth1 --mode osra
```

Evaluation outputs are written to:

```text
evaluation_results/diff_train/
evaluation_results/osra/
```

```bash
for d in etth1 ettm1 electricity exchange traffic weather
do
  python diff_train.py --dataset $d
  python osra_train.py --dataset $d
  python evaluate.py --dataset $d --mode diff_train

```

## Evaluation Metrics

We report two groups of metrics.

### Distance-oriented fidelity metrics

| Metric |       Direction | Description                                 |
| ------ | --------------: | ------------------------------------------- |
| MSE    | lower is better | point-wise mean squared error               |
| MAE    | lower is better | point-wise mean absolute error              |
| DTW    | lower is better | shape similarity under dynamic time warping |
| KLD    | lower is better | step-wise marginal distribution discrepancy |

### Semantic control metrics

| Metric         |        Direction | Description                                       |
| -------------- | ---------------: | ------------------------------------------------- |
| Trend Acc      | higher is better | accuracy of generated trend category              |
| Volatility Acc | higher is better | accuracy of generated volatility category         |
| Peak Acc       | higher is better | accuracy of generated peak-location category      |
| Avg. Semantic  | higher is better | average of Trend, Volatility, and Peak accuracies |

## Reproducing Paper Results

To reproduce the main single-sample results:

```bash
for d in etth1 ettm1 electricity exchange traffic weather
do
  python diff_train.py --dataset $d
  python osra_train.py --dataset $d
  python evaluate.py --dataset $d --mode osra
done
```

The reported results in the paper are averaged over multiple random seeds unless otherwise specified. For exact reproduction, use the same fixed data split and random seed configuration as provided in the preprocessed metadata and training scripts.

## Notes on Reproducibility

* All text-conditioned methods use the same preprocessed prompt embeddings.
* Semantic evaluation uses deterministic observable attributes extracted from generated sequences.
* The supported semantic attributes are trend direction, volatility level, and peak timing.
* The code uses a fixed split file `{dataset}_train_indices.npy` for each dataset.
* GPU results may vary slightly across hardware and CUDA versions.
